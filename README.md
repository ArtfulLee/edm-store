# EDM Store

Electronic Dance Music Store (WIP)

## Instructions 📋

- Download project
- Download [`NodeJS`](https://nodejs.org/en)
- Run terminal inside this folder
- Run npm install for install dependencies
- After that, run `npm run dev` for running the project
- After that, run `npm run server` for running the json-server

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

## Technologies used

This project combines the following:

- HTML5
- CSS3
- JavaScript (ES6)
- Vite
- React
- React Router Dom
- Zustand
- Tailwind
- JSON server
- nanoid
- ESLint
